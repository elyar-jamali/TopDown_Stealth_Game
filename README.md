# TopDown Stealth Game

A top-down stealth game developed with Godot 4.

## About

This project is an experimental stealth game built from scratch using Godot Engine.
The goal is to create a small but expandable stealth experience with interactive environments, NPC behaviors, and modular game systems.
This is a hobby project for my spare times

## Engine

- Godot 4.x
- GDScript

## Current Features

- Top-down player movement
- Click-to-move system using NavigationAgent3D
- Interactive objects system
- Reusable door scenes
- NPC basic structure
- Hover interaction system
- Custom cursor states
- Main and ingame menu system
- Settings panel
- Dynamic localization system
- JSON based language files
- Language selection and persistence


## Planned Features

- Save / Load system
- Key remapping
- Inventory system (maybe)
- More advanced NPC AI
- Multiple levels
- Character customization

## Status

Early development.

The project is currently under development and systems are being built incrementally.
